# 知识验证与发布记录

## 验证对象

候选 ID、内容校验值、原版本/新版本、适用范围、风险等级、依赖和来源证据。

## 验证计划

待检验结论；对照基线；代表性与边界输入；可机械核对的验收条件；不可执行的外部副作用；测试环境；模型和思考配置；预算和停止条件。

## 实际证据

每次执行独立编号、时间、环境、输入和成果引用、观察事实、原因推断、失败类别及验收主体。未运行写未运行，不能用计划当证据。重复来源归入同一独立性分组。

## 验证结论

满足条件的范围、未覆盖情况、反例、是否需要额外复现。比较质量达标后再看时间与成本。合并版本不能直接继承旧版本的测试通过状态。

## 发布授权

保留政策；发布域；审批主体和策略版本；内容绑定；有效期；撤销方式。验证正确与允许发布分开。

## 运行时执行回执

新版本/关系、索引和 Wiki 更新计划、受影响任务、旧版本处理、证据交接、清理范围。不因一份自然语言“批准”绕开身份、权限和版本校验。
