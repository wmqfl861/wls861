# 通用基础包规格｜v1 设计草案

**WLS-TOOLS-SPEC-001 · 2026-10-17 · 已同意方向，未安装或实现**

## 1. 交付定位

通用基础包不是现成发行版软件名，而是成熟程序、统一工具接口、受控执行环境、角色配置和自动检查的组合。C++ 核心负责治理；外部程序可用其他语言。基础环境公共安装一次，按版本复用，团队只分配私有空间与会话。

## 2. 默认能力

| 分组 | 能力 | 边界 |
| --- | --- | --- |
| 文件读取 | 列目录、定位、分页读取、搜索 | 授权输入与本团队空间，明确输出截断 |
| 文件修改 | 新建、写入、精确补丁、差异 | 版本/旧内容校验，默认不修改用户原件 |
| 进程管理 | 启动、状态、输出、停止 | 异步编号，超时/资源/进程树管理 |
| 协作管理 | 任务、调整、进度、问题、成果提交 | 按角色开放，不自由改验收状态 |
| 能力发现 | 工具契约、版本、Skill 依赖 | 可发现不等于已授权可执行 |

建议基础可复用环境评估 Bash、Git、ripgrep、Python 等；开发编译器、Node.js、浏览器、OCR/文档转换等是按需扩展，不把全部生态装进最小包。具体发行版、安装源、版本和镜像摘要待确定。

## 3. 四角色工具包

Root 使用 gateway 管理能力；Dispatcher 使用 orchestration；TeamLead 使用 team_coordination；Worker 使用 worker 基础执行包并叠加功能工具。管理角色可读授权资料/成果视图，不能因此任意浏览宿主文件系统。

模型未设继承 Root；工具未设采用角色包和任务政策，不继承 Root 工具列表。功能包提出能力需求，最终权限是系统政策、角色边界和任务授权的交集。关键管理接口被禁用则配置检查报错，不能启动一个无法反馈的团队。

## 4. 统一工具契约

注册 stable_tool_id、version、source、input_schema、output_schema、operation_class、dependencies、limits、cancellation_support、credentials_ref、permission_requirements、determinism/cache_policy。工具注解不自授权限，身份和请求关联由宿主填充。

执行入口核对任务/需求版本、有效代次、权限和资源。显式程序路径与参数优先；需要 Shell 语义时使用受控执行。标准输出、错误、退出状态、截断标志与成果引用清楚区分，不靠文本“成功”判定。

长操作返回 operation_id。取消有 requested/in_progress/cancelled/not_cancellable，已发生副作用另行核对；未知结果不盲重试。重复派单与执行幂等不是同一保证。

## 5. 环境、隔离与依赖

运行身份无默认系统管理员权限；只读输入、可写团队空间、网络和凭据按任务授予。公共依赖由受控安装器维护，不能所有 Worker 任意改公共缓存。文件工具、Shell、MCP 和其他执行路径统一受限，避免经不同入口越权。

安装需要的权限不转给运行代理。进程资源限制、文件系统/网络隔离与系统调用限制分开设计。容器/沙箱选型需在目标 Linux 上核验，不能仅凭“用了容器”宣布安全。

每团队绑定环境版本，升级影响新团队；紧急安全问题可暂停或迁移。依赖未就绪、未授权、版本不兼容、临时不可用用不同错误说明，不让模型无界扫描磁盘或自动全局安装。

## 6. 外部工具与插件

MCP、CLI、库、HTTP 服务和供应商托管工具各有适配器；统一注册、调用、授权和用量。第三方 Agent 的 spawn/agent/message/task 工具不能原样开放绕过本系统组织关系。完整外部 Agent 作为委派能力接入，对其内部不可假定同样四层。

Skill 的正文不复制所有当前参数，引用稳定能力与兼容范围。固定工具定义和排序减少上下文漂移；发现可按需加载，不能全库定义无界注入。

## 7. 生命周期与清理

共享无状态程序可以复用；带账号、工作目录、浏览器状态和任务内容的会话须隔离。交付回收私有进程、工作区、凭据租约和会话，不卸载公共工具、不删其他任务数据。工具返回日志是否长期保留遵守同一请求政策。

## 8. 初始检查与验收

安装检查验证程序存在、版本和依赖；工具闭环检查授权读写/搜索/补丁、失败与退出状态、长进程输出与取消；边界检查跨团队文件访问、网络、凭据、重复调用、并发、进程后代和清理；模型检查调用请求经校验执行并回到正确任务。

这些检查必须最终在目标 Linux 上运行并留证。本包只有拟定用例，未执行安装、沙箱或模型闭环测试。
