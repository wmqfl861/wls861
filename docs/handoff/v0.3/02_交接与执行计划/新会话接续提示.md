# 给下一位开发者或下一次会话的接续说明

请先阅读本包的项目交接文档、综合设计 v0.3、统一记忆引擎规格及决策/待定清单，再查看 v0.1/v0.2 原件。以用户明确要求和后续修订为准，不把建议当已批准。

本项目为无量山 C++ 通用多 Agent 系统，Linux 优先，后续保留 Windows。所有功能使用 Root→Dispatcher→TeamLead→Worker。Root 只对外；每个独立请求有 Dispatcher；Dispatcher 管多个 TeamLead＋Worker 团队；只有 Worker 执行业务工具。请求并发、版本化变更、审核交付与受控回收必须统一。

模型和思考等级逐字段独立配置，未设直接继承所属 Root。通用基础包方案已同意，但尚未安装；当前没有产品源码或已通过的业务测试，不得声称“已有运行内核”。其他搜索工具/动画项目不属于本交付。

记忆统一事实、经历、规则、Skill 和成果证据。自生/下载均有来源、标签、条件；Wiki＋RAG阶段激活；强制规则由运行时执行。交接有经验报告及可选 Skill 补丁；候选验证授权后发布。方法冲突先并存，实际独立证据加权，带条件合并再验证，归档旧内容。使用次数不等于正确，失败警示不能因方法不推荐而丢失。

建议独立 MemoryEngine＋MemoryBridge，首版同进程内置，后可服务化；该部署路线尚待用户确认。TaskEngine、ToolRegistry、PolicyEngine 是当前状态/接口/权限的权威，不能用旧记忆替代。

开始真实执行前明确：目标 Linux、模型端点/凭据、并发预算、工具隔离、对外交付回执、严格清除/经验保留、知识审批和验证阈值。没有授权不得因配置样例执行真实外部操作、自动永久保存或删除数据。

推荐先实现无模型的任务/事件/版本/资源生命周期，再接工具和一个端点，再实现工作流及记忆闭环。每批产出源码、构建与实际测试证据；拟定验收 CSV 全部初始状态是“未执行”。

聊天文件是用户原文＋助手要点的整理版，不是平台全量逐字导出。历史资料中供应商 API/缓存与 Hermes 行为的最新状态需在实现前重新核验。
