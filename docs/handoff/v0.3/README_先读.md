## 三个重要边界

**没有可运行产品源码、二进制、实际安装或业务测试成绩。** 本包的51项验收用例全部为未执行，不借用其他项目的代码和测试结果。

**聊天是整理档案，不是平台全量逐字导出。** 用户消息来自当前可见原文，助手部分为逐轮摘要；没有精确消息时间和不可见会话。不能把摘要作为逐字引用。

**打包不执行清理或发布。** 原件没有删除，没有安装程序、调用生产模型或变更外部账号。知识长期保留和严格清除的生产政策尚待明确。

## 建议接手续作

先读交接文档与待决策项，再评审核心契约；第一批实现无模型状态/事件/版本/资源闭环。随后接工具、一个端点、工作流和记忆闭环。部署前核验当前API与依赖版本，不把历史参考当最新能力保证。

## 校验方式

解压到同一目录后，在包根目录运行：

```sh
sha256sum -c 06_清单与校验/SHA256SUMS.txt
```

该清单覆盖除自身外的包内文件。`文件清单.json`记录数据文件（不含清单自身和SHA文件）；清单本身由SHA文件覆盖，避免自引用。外部ZIP校验文件用于检查下载后的压缩包。

CSV 使用 UTF-8 BOM 方便常见表格软件打开；JSON、YAML、Markdown、HTML 使用 UTF-8。HTML无外部脚本、字体或网络依赖。包内未包含渲染中间图、字体文件或打包辅助脚本。
