# 决策记录（ADR）

本文件登记所有架构与政策决定。规格正文（01–07）必须与这里一致；要改任何一条，先在文末"提议"区追加一条，由项目所有者批准后再改规格和代码。

状态说明：

- **已确认**：项目所有者明确表态（聊天原话或 2026-10-17 的拍板）。
- **已采纳**：来自 v0.3 审核建议，所有者表示"按你推荐的做"或未提异议；可随时推翻。
- **默认值**：可直接开工的起步值，跑基线后调整。
- **延后**：到指定时点前再定，不阻塞之前的工作。
