# ADR-067：有界、作用域绑定的原始历史读取

状态：接受；R1 第一个可独立交付的子项。基线 `aa0f79b1eb306102449a6a463de3bcdc93d58a74`。

## 问题与决定

旧 `attempt_history` 将完整历史一次性返回，超过256条或8 MiB即拒绝。直接缩短数组会
静默丢失原观察，而重复读取工作区无法恢复当时的字节。R1窗口与结构化消息需要先有一个
可访问全部原始证据、但单次内存和输出有界的读取接口。

增加独立的 `attempt_history_page` 元数据索引和 `read_history_feedback` 原字节分片：

- 身份来自受信宿主，查询限定 request/role/principal/task/team，仍验证当前执行代次。
  游标不是权限；非零游标必须来自同一作用域。旧记录的绑定永不盖成当前版本。
- 首页固定 `through_sequence`（该作用域当前最大插入序号）；后续页沿用它，追加记录不
  混入本次遍历。每页最多64项，游标是排他的 `after_sequence`，序号不要求连续。
- 索引只给标识、状态、原绑定和反馈哈希，不加载旧完整请求或工件正文。反馈缺失明确标记，
  不从现在的文件或执行器补写。索引是事实定位器，不宣称业务成功。
- 原反馈的 response/result 分片要求调用方提供原 `record_sha256`；验证完整反馈事实指纹、
  所属调用原绑定与原响应一致后才返回。每片最多16 KiB，按UTF-8 JSON字节偏移，以base64
  承载，允许分片落在UTF-8字符中间；完整重组后再解码JSON。
- 返回完整section SHA-256、字节长度、原绑定、EOF/next_offset；不裁剪原记录，不变更SQL
  资产，不新增写事务、事件、预算消费或恢复围栏。

## 兼容与范围

保留原 `history --limit` 和 `attempt_history` 的完整或失败语义。新增只读宿主 CLI
`history-page` / `history-read`，不注册为模型业务工具，不扩大 Worker 授权，不绕过UNKNOWN
来执行任意命令。缺失反馈、过期身份、跨作用域、错误哈希和越界页均明确失败。

本子项只建立R1证据回读基础；不宣称已实现上下文窗口、自动压缩、原生供应商tool消息或
模型适配。当前Worker仍使用旧全历史编译，60KB重复读取触顶问题保持开放；下一子项必须
将有界窗口和结构化消息接入运行器，携带明确的历史遗漏索引与回读能力，并证明跨重开可继续。

## 验收

超过256条的完整分页、页间新增与作用域交错、跨请求/团队/角色游标与反馈拒绝、错哈希及
损坏拒绝、缺失反馈不补造、二进制/中文内容逐字节重组、重开后原绑定与字节不变、读取不
改变数据库/预算/epoch。保留完整Release、UBSan、ASan和普通用户回归。
