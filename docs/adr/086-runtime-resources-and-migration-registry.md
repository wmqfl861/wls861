# ADR-086：编译认可的运行资源与兼容迁移注册表

日期：2026-10-26（America/Los_Angeles）。基线：
`1c572d3aa9121e85cf22aa1e4bb330b25a34a143`，Store 410。

## 背景

蓝图 14.3 和 `R3-controlled-live-plan.md` 第 7 节要求在服务化之前完成迁移注册表和
资源安装契约。原 CLI 从源码目录读取 SQL、Schema 和提示词，Store 的原构造函数接收
逐份可信宿主 SQL。直接扫描迁移目录或者信任分发文件自报的 hash，会把文件系统内容
变成新的结构修改权限；直接重写迁移引擎则会无谓改变已验收的事务、锁和恢复边界。

运行资源也不同于用户配置。端点、模型别名、认证引用和预算仍由外部配置显式提供；
请求保存自己的冻结配置，安装另一个程序版本不能偷偷改变已有请求。

## 决定

1. 增加 `RuntimeResources`。编译注册表固定当前 35 份 SQL、Schema 和公共提示词的
   路径、类型、大小及 SHA-256；版本化 manifest 必须与完整编译注册表一致。缺少、
   多出、重复、乱序、未知版本及自报新 hash 均不能获得运行资格。
2. 每份资源在数据读取前用 `O_PATH | O_NOFOLLOW` 检查路径组成和普通文件类型，
   再从已固定的文件描述符读取原字节。清单、单文件和总量分别有界；实际 EOF、
   原大小、前后文件身份和 hash 都成立后才返回完整资源对象。FIFO、符号链接和
   特殊文件拒绝在数据读取之前。Schema 和迁移使用捕获的原字节，不重新打开资源路径。
3. 增加 `MigrationRegistry`，明确注册原 401→402 至 409→410 的连续迁移、原 hash、
   元数据表和目标版本。支持 402–410 的连续前缀，默认 410；不扫描任意目录，不执行
   未注册 SQL。本批不增加迁移，不修改已发布 SQL 字节。
4. 新 `Store(path, registry, mode, scope)` 构造函数委托原可信 SQL 构造函数。
   保留每步事务、迁移 hash 验证、单写者、只读行为、请求范围以及带请求升级的
   显式全库维护要求。原十三参数接口继续可用，包括已有故障 SQL 回滚测试；它仍是
   可信宿主接口，不因此升级为可接收模型 SQL 的接口。
5. CMake 安装 `bin/wls`、`bin/wls861` 与 `share/wls861`，支持 prefix 和 `DESTDIR`。
   安装器先捕获并验证全部资源，再逐文件发布；资源文件为 0444。新目录请求 0755
   并保留调用方 umask，已有目录权限不改变。配置、端点、凭据和用户数据不进入 bundle。
6. 新 `--resource-root` 显式选择已安装 bundle，`--source-root` 保留源码兼容模式；
   两者互斥。没有显式根目录时，只从实际可执行文件的固定相对位置发现。
   cwd、PATH 和环境变量不选择资源；首个已存在清单无效时直接拒绝，不继续降级寻找。
7. 已安装模式要求显式 `--config` 和 `--functions-dir`。源码模式保留原默认示例配置。
   默认分发提示词冻结后必须与已捕获原字节一致；显式外部 `--prompts-dir` 则作为
   普通请求配置冻结。资源身份和请求配置身份分别报告，不互相替代。

## 失败、兼容和边界

资源完整性验证先于 Store 构造，坏资源不能创建数据库或取得写者租约。旧数据库及其
冻结配置保持原解释；新资源注册表不会修改历史请求、事件、结算或原迁移元数据。
新 Schema 字节入口沿用原文件大小、总量、名称、draft、ID、引用和模型输入投影约束。

安装是逐文件原子替换，manifest 最后发布，不是整套 bundle 的原子切换。中途失败或
程序与资源版本混合时，后续启动必须拒绝不一致；已经完整捕获的进程继续使用自身原字节。
安装前缀由可信安装操作者管理。路径检查拒绝符号链接和特殊文件，但不提供对同 UID
攻击者搬移整个目录树的独立隔离。源文件类型/hash 错误在安装器创建资源目标前拒绝；
CMake 安装目标的其他步骤仍可能已完成，整个 `cmake --install` 不声称全局事务性。

`/proc/self/exe`、`/proc/self/fd` 和 Linux 描述符语义属于当前运行平台；无法获取实际
可执行路径时要求显式资源根。此模块不安装服务、不启动 daemon、不捆绑凭据，也不
授予任何模型调用或业务工具权限。

## 验收

专项覆盖编译清单与源/bundle 相同身份、缺失/篡改/自报 hash/重复键/未知版本、
实际 FIFO、大小边界、捕获后删除资源、所有注册前缀、旧接口、逐步回滚、只读、
单写者及显式全库升级。普通用户真实执行 CMake prefix/DESTDIR 安装、重定位、
非源码 cwd、删除安装来源、显式外部配置及冻结请求兼容。

接口和操作契约见 [运行资源与迁移契约](../implementation/runtime-resources-and-migrations.md)。
实际执行结果单独记录于专项报告，不能把上述验收设计当作已经通过的运行证据。
