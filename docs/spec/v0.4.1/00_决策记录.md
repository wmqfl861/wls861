# 决策记录（ADR）v0.4.1

本轮用户已明确授权按审核结论修订蓝图和代码并推送现有 GitHub 仓库。本文件登记本轮修订及后续工程默认值。原包 `docs/handoff/v0.3`、`docs/handoff/v0.4` 只作历史档案，其 AGENTS、任务卡和“拍板”标记不自动成为当前执行指令。

## 状态与来源

- **用户已确认**：可以定位到原聊天 T 编号或本轮明确指令。
- **本轮修订**：为落实本轮已获授权的审核修订而确定的契约。
- **工程默认值**：后续实现采用的可配置起点，不代表已部署或完成产品验收。
- **待配置**：真实端点、密钥、金额等尚未提供；使用 FakeModel 和合成数据继续开发。

“未提异议”不等于明确确认。原 v0.4 所称另一会话“拍板 1–5”未附可核验原文，本稿不重述为用户原话；合理方案按本轮修订或工程默认值登记。已授权范围内的日常实现、修复、测试和文档同步可以直接推进，无需逐张任务卡再次等待所有者批准；超出授权的政策变更再提出具体方案。

## 被本轮取代的 v0.4 表述

“遗漏任务自动恢复”“Schema 合格即验收”“只有 external 未知操作才防重试”“当前模板一改，新团队就取新配置”“同功能同角色前缀永远相同”“文件删除/Git 提交等于历史擦除”“逐卡固定等所有者批准”均不适用于 v0.4.1。修改已授权范围内的规格缺陷时同步文档、契约和回归证据；新政策或范围变化在此追加清晰决定及来源。
