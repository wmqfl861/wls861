# 需求追踪 v0.4.1

需求以聊天档案原话（T01–T21）及本轮明确授权的审核修订为准。本表把每条需求对到规格章节、决策和验收用例；第 2、3 节给出 v0.1、v0.3 旧编号的对照。目标蓝图仍为 **v0.4.1**；当前 **S1 基础增量 / S1.1** 新增本地 `wls 0.2.0-s1.1`，第 5 节追踪本批实际实现子项和剩余范围。

实现状态以 [S1 基础增量契约](../../implementation/S1-foundation.md) 为准，执行结果以 [本批验证报告](../../reports/s1-foundation-validation.md) 为准。下面的需求/验收映射不是完成标记；原 51 项产品验收记录仍保持未执行，M1、Python 参考契约和 S1.1 C++/离线集成证据分别记录。
