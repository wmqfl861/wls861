# 验收计划 v0.4.1

本文件是计划，不是通过报告。基线 M1 已有源码、构建和历史报告；当前新增 **S1 基础增量 / S1.1**，本地 `wls` CLI 版本为 **0.2.0-s1.1**，目标蓝图仍为 **v0.4.1**。C++ 配置/Store/模型/上下文与离线集成的可执行范围见 [S1 基础增量契约](../../implementation/S1-foundation.md)，实测结果见 [本批验证报告](../../reports/s1-foundation-validation.md)。[M1 报告](../../reports/M1-validation.md) 与 [v0.4.1 修订报告](../../reports/v0.4.1-validation.md) 保留各自版本的历史证据。

原 v0.3/v0.4 档案不改，原 51 项产品验收记录继续保持未执行。本批增加实现子项与回归证据，不改写下列产品通过标准，也不把 S1.1 标成完整 S1。真实模型、沙箱、业务交付和清理闭环仍待执行。

## 7. 基准方法

每功能先建立 15–20 个代表性任务及独立通过条件；同模型/工具/预算分别运行四角色与单 Worker，记录随机性、返工、失败、费用未知样本和运行环境。S3 加记忆开/关对照。质量或成本无改善就据数据修订策略，不因单次成功把复杂设计宣布有效，也不为得分绕过已确认四角色约束。
