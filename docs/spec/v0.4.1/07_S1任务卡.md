# S1 任务卡 v0.4.1：承接 M1 的最小真实闭环

目标仍是“真实任务 → 中途改方向 → 当前版本验收与交付 → 可恢复清理”。在已验证的 M1 内核和 v0.4.1 契约之上，本批交付 **S1 基础增量 / S1.1**：C++ SQLite Store、严格 JSON/YAML 与 Schema 校验、请求配置冻结和恢复、FakeModel 与持久调用账本、ContextCompiler，以及连接这些模块的单任务离线运行器和本地 `wls` CLI。新 CLI 版本为 **0.2.0-s1.1**，目标蓝图仍为 **v0.4.1**。

当前可执行范围以 [S1 基础增量契约](../../implementation/S1-foundation.md) 为准，实际命令、结果和限制以 [S1 基础增量验证报告](../../reports/s1-foundation-validation.md) 为准；历史 M1 能力继续由 [M1 契约](../../implementation/M1-contract.md) 单独描述。文件/进程业务工具、真实沙箱、完整角色事件循环、真实模型、业务交付和可恢复清理仍待后续增量。S1.1 不是整阶段 S1 完成。

用户已经授权本轮修订和 push。任务卡指导增量工作，不要求每张卡再次等待所有者批准，不创建空仓库，不把历史验收表改成通过。
