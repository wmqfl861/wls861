1. 上一轮计划的 G1 部分全部落地：30 小时合并 14 个 PR，产品代码 2,936 行，每个 PR 都在预算内。PR 门禁约 11 分钟。

3. 合成门禁测不出真实模型能不能用。按现在的 main 接真实端点，有 4 个阻断问题：
   - 计划里的任务说明，模型看不到它的结构，宿主却按完整结构校验。
   - 校验失败时模型只收到一句固定的话，不知道错在哪里；连续两次即停。
   - Schema 之后的规则检查失败会直接停批，其中约束相关的字段本应由宿主填写。
   - 任何一次失败的模型调用（限流、超时、输出被截断）都会让请求永久卡住，没有办法解除。
4. 另有 8 个会频繁打断运行的问题和 4 个成本问题，见 `01-audit-report.md` §6、§7。
5. 下一步是一个很短的 G2-P 阶段（约 10 个小 PR，产品代码约 1,650 行），出口是一个模拟真实模型常见错误的预演门禁。然后做 G2。
